### Partie code

Le modele MoE est implemente avec 4 experts et un gating soft.  
Le modele dense baseline est aussi implemente.  
Les entrainements fonctionnent correctement, autour de 97.6% pour le MoE et 98.0% pour le dense.  
Les notebooks permettent d analyser le modele entraine et la repartition du gate.  
La heatmap du gate est exploitable et montre une specialisation des experts.



## Comment relancer le projet sous Windows

Le projet se relance depuis un terminal PowerShell en activant l environnement virtuel, puis en lancant les scripts d entrainement ou les notebooks Jupyter selon le besoin.
